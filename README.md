### [SlotFix](https://www.nexusmods.com/warhammer40kdarktide/mods/982)
**The short version:** Fixes a bug in the game that results in players appearing black or having no slot.

**The details:** Standalone mod that fixes a bug in the game that results in players appearing black or having no slot. It checks what slots people are in and reassigns them to a valid slot. I also added a toggle to show debug messages in chat if you want to see when it catches a bug. REQUIRED BY COLOR SELECTION but is completely functional if you don't have color selection!
